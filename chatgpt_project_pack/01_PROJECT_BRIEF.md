# AI Tutor VN — Project Brief

Build a Vietnamese-first AI tutor that improves learning rather than merely producing homework answers.

Core loop: problem intake → analysis → explicit tutor state machine → student attempt → verification → misconception → mastery → next action.

Current architecture: Next.js frontend + FastAPI backend + PostgreSQL + OpenAI model integration, kept as a modular monolith.

Immediate product focus: stabilize baseline, then Tutor Engine, controlled curriculum skills, deterministic verification, mastery evidence and evals. Camera, voice and rich dashboards come later.
