Two question identities have different semantics and must remain separate:

```text

= question used to START this tutor session

```


## Persistence semantics

### Ordinary/free-form tutor session

When code constructs:

```python
TutorSession(student_id=...)
```

without authored provenance:

```text
authored_question_id is None
```

### Authored provenance

The ORM must round-trip:

```text
g8alg.factorization.001
```

or another representative question-bank ID exactly.

### Independence from transfer provenance

The same `TutorSession` must be able to hold both fields independently:

```text
authored_question_id = "..."
transfer_question_id = "..."
```

Changing one must not change the other.

The two fields may contain different question IDs.

This task does not decide when runtime code sets either field.
