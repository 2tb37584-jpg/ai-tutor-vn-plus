# M05-04B1 — Add Internal Expected-Answer Storage

Status: ACTIVE
Codex: YES — SMALL

## Goal

Add durable server-internal storage for the expected answer on TutorSession so a later runtime leakage guard can compare tutor output against the expected answer across reply requests.

This task adds storage only.

It does NOT wire `/tutor/start` yet and does NOT implement leakage detection.

## Context

`ProblemAnalysis.expected_answer` currently exists only during problem analysis.

`/tutor/reply` later has access to the persisted TutorSession but not the original expected answer.

A later runtime leakage guard therefore needs durable internal expected-answer context.

## Required model change

Add to `TutorSession`:

`internal_expected_answer`

Requirements:

- type: Text
- nullable: False
- application default: empty string
- intentionally server-internal
- do not import or couple to ProblemAnalysis

Conceptually:

`internal_expected_answer: Mapped[str] = mapped_column(Text, nullable=False, default="")`
