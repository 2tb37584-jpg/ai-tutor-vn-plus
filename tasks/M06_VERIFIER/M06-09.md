## Goal

Implement a pure deterministic policy resolver that combines:

- verifier status;
- model `likely_correct`;
- retry count;

into one reusable verification decision.

Do not wire it into API, TutorAI, state transitions, or mastery yet.

## Context

M06-08 established:

- deterministic `CORRECT` / `INCORRECT` is authoritative;
- model `likely_correct` is advisory;
- `UNSUPPORTED` means no deterministic verdict and is not retryable;
- `INDETERMINATE` allows at most one deterministic retry;
- unsupported/indeterminate evidence is not mastery-eligible;
- model-only correctness is not mastery-eligible.

## Required behavior

Input verifier status uses the existing verifier enum:

```text
CORRECT
INCORRECT
UNSUPPORTED
INDETERMINATE
```

Suggested types:

```python
class EffectiveCorrectness(str, Enum):
    CORRECT = "correct"
    INCORRECT = "incorrect"
    UNKNOWN = "unknown"


class EscalationAction(str, Enum):
    ACCEPT_DETERMINISTIC = "accept_deterministic"
    RETRY_DETERMINISTIC = "retry_deterministic"
    MODEL_ASSISTED_ONLY = "model_assisted_only"


@dataclass(frozen=True)
class VerificationDecision:
    correctness: EffectiveCorrectness
    action: EscalationAction
    mastery_eligible: bool
    disagreement: bool
    retry_allowed: bool
```

The exact names may vary slightly if needed, but semantics must remain explicit.

Decision rules:

```text
CORRECT
    correctness = CORRECT
    action = ACCEPT_DETERMINISTIC
    mastery_eligible = true
    retry_allowed = false

INCORRECT
    correctness = INCORRECT
    action = ACCEPT_DETERMINISTIC
    mastery_eligible = true
    retry_allowed = false

UNSUPPORTED
    correctness = UNKNOWN
    action = MODEL_ASSISTED_ONLY
    mastery_eligible = false
    retry_allowed = false

INDETERMINATE, retry_count = 0
    correctness = UNKNOWN
    action = RETRY_DETERMINISTIC
    mastery_eligible = false
    retry_allowed = true

INDETERMINATE, retry_count >= 1
    correctness = UNKNOWN
    action = MODEL_ASSISTED_ONLY
    mastery_eligible = false
    retry_allowed = false
```

Disagreement rules:

```text
CORRECT + model False -> true
INCORRECT + model True -> true
all other combinations -> false
```

For `UNSUPPORTED` and `INDETERMINATE`, model output is advisory and does not count as a true correctness disagreement.
