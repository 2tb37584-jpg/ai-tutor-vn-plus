# M00-01 — Local baseline validation

Status: DONE
Codex: NO

## Goal
Prove what currently runs on the user's machine before feature development.

## Steps
1. Copy `.env.example` to `.env`.
2. Add required local secrets.
3. Run `docker compose up --build`.
4. Verify backend `/health` and `/docs`.
5. Verify frontend opens.
6. Run backend tests.
7. Exercise one flow: register/login → student → text problem → tutor session.
8. Record every failure in `tasks/M00_BASELINE/BASELINE_RESULTS.md`.

## Acceptance criteria
- [ ] exact commands used are recorded
- [ ] backend test result is recorded
- [ ] frontend startup result is recorded
- [ ] API smoke-flow result is recorded
- [ ] every blocker has reproducible error text

## Output
Do not fix broad issues in this task. Capture a trustworthy baseline first.
