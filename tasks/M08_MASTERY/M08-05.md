## Goal

Add a deterministic v1 next-best-question recommender with no DB/API dependency.

Integrate existing:
- question bank;
- direct prerequisite graph;
- mastery snapshots;
- review scheduler;
- authored difficulty.

Do not add a weighted scoring framework, learned ranking, persistence, randomization, or attempt-history logic.

## Typed input

Create:

```python
@dataclass(frozen=True)
class MasterySnapshot:
    skill_code: str
    probability: float
    exposures: int
    last_seen_at: datetime | None
```

Do not import the ORM `Mastery` model.

Missing mastery for a bank skill is treated as unseen:

```text
probability = 0.35
exposures = 0
last_seen_at = None
```

## Required API

Implement a deterministic function equivalent to:

```python
recommend_next_question(
    *,
    mastery_snapshots: Iterable[MasterySnapshot],
    now: datetime,
) -> QuestionBankItem
```

No database call. No runtime clock call. No LLM call.

## Prerequisite eligibility

A root skill with no direct prerequisites is eligible.

A skill with direct prerequisites is eligible only when every direct prerequisite has a mastery snapshot with:

```text
exposures > 0
probability >= 0.80
```

Missing prerequisite mastery blocks the dependent skill.

Use direct prerequisites only in v1. Do not add transitive traversal.

## Skill priority

For each eligible skill represented in the question bank:

- use its mastery snapshot when present;
- otherwise use the unseen fallback;
- call existing `schedule_review(...)`.

Classify:

```text
priority 0 = seen and due
priority 1 = unseen
priority 2 = seen and not due
```

where:

```text
seen = exposures > 0 and last_seen_at is not None
```

Within the same class, lower probability wins.

Final tie-breaker: question-bank declaration order.

No weighted score.

## Target difficulty

After choosing the skill:

```text
unseen or probability < 0.50 -> target 1
0.50 <= probability < 0.80 -> target 2
0.80 <= probability <= 1.00 -> target 3
```

Choose a question for that skill by:

1. smallest absolute distance from target difficulty;
2. equal distance -> lower difficulty;
3. remaining tie -> question-bank declaration order.

## Validation

Raise `ValueError` for:
- duplicate mastery snapshots for the same skill;
- unknown/non-canonical skill code;
- invalid mastery values rejected by existing scheduler rules;
- invalid `now`;
- naive/aware datetime mismatch.

Do not resolve aliases implicitly.
