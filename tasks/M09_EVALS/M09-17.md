## Summary command

```powershell
@'
import json
import os
from pathlib import Path

p = Path(os.environ["TEMP"]) / "ai-tutor-phase1-final-100-report.json"
report = json.loads(p.read_text(encoding="utf-8"))

print("CASE_COUNT:", report["case_count"])

    print(
        name,
        "pass=", metric["passed"],
        "fail=", metric["failed"],
        "not_scored=", metric["not_scored"],
        "rate=", metric["rate"],
    )

print("\nLIVE EXECUTION ERRORS:")
live_errors = []
for case in report["cases"]:
    for name, metric in case["metrics"].items():
        details = metric.get("details") or {}
        if details.get("reason") == "live_execution_error":
            live_errors.append(
                (case["id"], name, details.get("error_type"))
            )

if not live_errors:
    print("NONE")
else:
    seen = set()
    for item in live_errors:
        key = (item[0], item[2])
        if key not in seen:
            seen.add(key)
            print("case=", item[0], "error_type=", item[2])

print("\nSCORED FAILURES:")
failures = []
for case in report["cases"]:
    for name, metric in case["metrics"].items():
        if metric.get("status") == "fail":
            failures.append(
                (
                    case["id"],
                    name,
                    metric.get("details") or {},
                )
            )

if not failures:
    print("NONE")
else:
    for case_id, metric_name, details in failures:
        print(
            "case=", case_id,
            "metric=", metric_name,
            "details=", details,
        )

print("\nUNKNOWN ACTUAL SKILLS:")
unknown_cases = []
for case in report["cases"]:
    metric = case["metrics"].get("skill_classification") or {}
    details = metric.get("details") or {}
    if details.get("unknown_actual_skill") is True:
        unknown_cases.append(case["id"])

print("count=", len(unknown_cases))
for case_id in unknown_cases:
    print(case_id)
```

## Handling live execution errors

If a case contains:

```text
reason = live_execution_error
```

do not rerun the full corpus.

For each unique affected case:

1. record the case ID;
2. create a one-case temporary JSONL outside the repository;
3. rerun that exact case once;
4. if the rerun produces scored results and all blocking metrics pass:
   - classify the original as transient execution variance;
5. if the rerun again returns `live_execution_error`:
   - final gate = FAIL;
   - open a separate structured-output/provider robustness task.

Do not silently ignore any execution error.

---

## Handling scored failures

A scored `fail` is blocking until investigated.

For a scored failure:

1. inspect the exact case and metric;
2. if model variance is plausible, rerun only that exact case once;
3. if the rerun still fails:
   - final gate = FAIL;
4. if the rerun passes but the same semantic failure has repeatedly appeared in earlier runs:
   - treat it as unresolved behavior;
   - final gate = FAIL;
5. do not modify code, prompts, taxonomy, scorer, or fixtures inside M09-17.

Any required fix becomes a separate task.
