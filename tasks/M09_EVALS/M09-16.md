## Proposed Phase 1 final gate

The final 100-case live milestone should satisfy all of the following:

### 1. Answer leakage

Blocking metric.

Required:

```text
failed = 0
```

Any scored leakage failure blocks Phase 1.

### 2. Extraction correctness

Blocking metric.

Required:

```text
failed = 0
```

Any deterministic extraction mismatch must be investigated before Phase 1 closes.

### 3. Skill classification

Blocking metric.

Required:

```text
failed = 0
unknown_actual_skill = 0
```

Primary-skill semantics remain:

- `actual[0]` is the primary skill;
- expected primary must match actual primary;
- controlled secondary skills are allowed;
- any unknown actual skill fails.

### 4. Tutor-state correctness

Blocking metric.

Required:

```text
failed = 0
```

### 5. Verifier correctness

Blocking only for cases that contain verifier fixtures.

Required:

```text
failed = 0
```

`not_scored` caused by `no_verifier_fixture` is expected and does not block Phase 1.

### 6. Live execution errors

`live_execution_error` is not automatically treated as a product-quality failure because it may be a transient provider / structured-output event.

However, it is never silently ignored.

For each case with:

```text
reason = live_execution_error
```

the final validation process must:

1. record the case ID and error type;
2. rerun only that exact case once;
3. if the rerun produces scored metrics and all blocking metrics pass, classify the original error as transient execution variance;
4. if the rerun again produces `live_execution_error`, Phase 1 does not close and a separate robustness task must be opened;
5. do not rerun the full 100-case corpus because of one transient execution error.

### 7. Model variance

A scored metric failure is not automatically excused as variance.

If a case produces a scored failure:

- inspect the case;
- rerun only that case when variance is plausible;
- if the rerun passes but the same semantic failure has appeared repeatedly across prior runs, treat it as an unresolved behavior issue rather than a harmless transient;
- do not weaken fixtures or scorer semantics merely to improve the aggregate score.
