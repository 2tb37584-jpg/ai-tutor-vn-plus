## Goal

Harden local single-family pilot Docker Compose defaults by binding published services to localhost, making PostgreSQL credentials configurable, and bounding Docker container log rotation. This does not authorize M09-41, grant pilot GO, or run a real pilot.

## Implementation requirements

1. Bind published frontend/backend/PostgreSQL ports to `${HOST_BIND_ADDRESS:-127.0.0.1}`; do not default to `0.0.0.0`.
2. Parameterize `POSTGRES_DB`, `POSTGRES_USER`, and `POSTGRES_PASSWORD`; preserve configurable `DATABASE_URL` and align the database health check with configured DB/user values. `.env.example` must identify a real-pilot password as requiring a private, non-default value.
3. Configure `json-file` logging with bounded `max-size` and `max-file` for `db`, `backend`, and `frontend`, preferably using safe configurable defaults such as `10m` and `3`. Rotation is not proof of the 30-day retention/deletion requirement.
4. Document `HOST_BIND_ADDRESS`, PostgreSQL variables, `DATABASE_URL`, `DOCKER_LOG_MAX_SIZE`, and `DOCKER_LOG_MAX_FILES` in `.env.example`; preserve OpenAI configuration and add no real secrets.
