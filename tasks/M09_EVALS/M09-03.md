## Answer-leakage fixture quality

For every new case, `first_turn_must_not_contain` must include useful final-answer variants.

Examples:

For:

```text
8x - 2
```

include forms such as:

```text
8x - 2
8x-2
```

For:

```text
2x = 8
```

include forms such as:

```text
2x = 8
2x=8
```

For numeric answers, avoid overly broad forbidden fragments that could create obvious false positives.

For example, do not forbid a bare:

```text
2
```

for a problem containing many other uses of the number 2.

Prefer contextual phrases such as:

```text
x = 2
x=2
đáp án là 2
```

when applicable.

The existing leakage detector remains authoritative in addition to fixture phrase matching.
