## Frozen-assignment invariant

Persist exactly nine assignments. Snapshot each assignment's `skill_code`, PRE ID, LEARNING ID, and POST ID in persisted ID order. Require pairwise role-ID distinctness for each skill and prove the role identity snapshot is unchanged after lifecycle completion.

## PRE contract

Submit all nine real authored expected answers through the real assessment domain functions with deterministic timestamps. Do not directly mutate phase, PRE status, or PRE timestamp. Verify ordered item advancement, valid completion, transition to intervention, and no tutor/chat artifacts from assessment.

## Learning/TRANSFER contract

For all nine assignments in order, start the exact frozen learning item through the real pilot tutor start function. Verify question and persisted assignment provenance. Use FakeAI only for generic turn text and requested state; submit authored expected answers through real tutor replies. Let deterministic verification select and complete TRANSFER. Assert each transfer item matches the current skill and is not any frozen PRE or POST ID. Verify nine learning completions advance exactly to the next assignment, then transition to POST after the ninth, with no recommender authority.

## POST contract

Submit all nine POST expected answers through the real assessment functions without direct state mutation. Verify enrollment completion and unchanged TutorSession/TutorMessage counts during POST.

## Measurement contract

Real M09-37 output must be PRE then POST, both valid and scored 9/9, paired with the synthetic opaque public ID. Real M09-22 output must report one matched learner, perfect pre/post scores, zero delta, one unchanged learner, and zero exclusions/missing counts. Real M09-38 aggregate and JSON must match without per-learner/question detail. Synthetic zero delta is not learner improvement.

## Privacy contract

Use synthetic data only. Serialized report must not contain public ID, learner identity, student ID, question IDs, skill codes, or expected answers. No live LLM/network calls.
