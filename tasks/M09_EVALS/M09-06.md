## Required 20 new cases

### 1. `g8-signed-numbers-nested-sign-001`

Problem: `Tính -(-6) + (-9).`

Skill: `arithmetic.signed_number_operations`

Expected answer: `-3`

Misconception: unary negation versus a negative operand. Use contextual leakage phrases; do not forbid bare `-3`.

### 2. `g8-distributive-double-parentheses-001`

Problem: `Khai triển 2(x + 3) - 3(x - 1).`

Skill: `algebra.expression.distributive_property`

Expected answer: `-x + 9`

Misconception: distributing the negative coefficient incorrectly across the second parenthesis.

### 3. `g8-distributive-negative-fraction-001`

Problem: `Khai triển -(1/2)(4x - 6).`

Skill: `algebra.expression.distributive_property`

Expected answer: `-2x + 3`

Misconception: handling both fractional and negative multipliers.

### 4. `g8-combine-like-terms-zero-coefficient-001`

Problem: `Thu gọn 5x - 2x - 3x + 7.`

Skill: `algebra.expression.combine_like_terms`

Expected answer: `7`

Misconception: variable terms cancel to zero. Use contextual leakage phrases; avoid bare `7`.

### 5. `g8-expression-simplify-nested-sign-001`

Problem: `Rút gọn 4 - [2x - (3 - x)].`

Skill: `algebra.expression.simplify`

Expected answer: `7 - 3x`

Misconception: nested subtraction and sign propagation.

### 6. `g8-expression-simplify-fraction-coefficient-001`

Problem: `Rút gọn (1/2)(4x + 6) - x.`

Skill: `algebra.expression.simplify`

Expected answer: `x + 3`

Misconception: distributing a fractional coefficient before combining terms.

### 7. `g8-equivalent-transform-add-variable-001`

Problem: `Từ 5x - 2 = 3x + 8, hãy viết phương trình tương đương sau khi trừ 3x ở cả hai vế.`

Skill: `algebra.equation.equivalent_transform`

Expected answer: `2x - 2 = 8`

Do not add a verifier fixture.

### 8. `g8-equivalent-transform-clear-denominator-001`

Problem: `Từ x/4 - 1 = 2, hãy viết phương trình tương đương sau khi nhân cả hai vế với 4.`

Skill: `algebra.equation.equivalent_transform`

Expected answer: `x - 4 = 8`

Do not add a verifier fixture.

### 9. `g8-linear-both-sides-verifier-001`

Problem: `Giải phương trình 5x - 2 = 3x + 8.`

Skill: `algebra.linear_equation`

Expected answer: `5`

Leakage should include `x = 5`, `x=5`, `đáp án là 5`.

Verifier:


### 10. `g8-linear-fraction-solution-verifier-001`

Skill: `algebra.linear_equation`

Expected answer: `3/2`

Leakage should protect `x = 3/2`, `x=3/2`, `x = 1.5`, `x=1.5`.

Expected answer: `x != 4`

### 18. `g8-rational-simplify-negative-factor-001`

Misconception: cancellation of one repeated factor while retaining the original excluded value.
