## Micro-task

Update the existing workflow document with the Phase/Workstream Delegation model and lifecycle gates. Do not create a generic workflow framework or change runtime behavior.

## Required workflow contract

- A whole Phase/workstream may be delegated only when architecture, task graph, measurable acceptance/exit criteria, test/eval strategy, and explicit stop conditions are known.
- A Phase must be decomposed as `Phase → workstreams → reviewable micro-tasks → deterministic gates → review checkpoints → Phase exit review`.
- ChatGPT retains authority over product direction, architecture, decomposition, trust boundaries, phase/workstream contracts, public API/schema decisions, student/minor privacy, eval strategy, checkpoint review, and phase exit.
- Codex may execute inside the approved contract: inspect seams, order micro-tasks, implement and test within scope, run focused/full deterministic regressions, update task docs, perform lifecycle transitions when gates are satisfied, and stage/commit/push/open PR only when explicitly allowed.
- Codex may move from planned task N to N+1 without relay only when the autonomous transition gate passes: focused tests, required regressions, exact scope, acceptance, no new architecture/trust/schema/API/persistence decision, and N+1 already in the approved workstream plan. Otherwise Codex stops.
- Mandatory review checkpoints cover architecture, public API, schema, database, authentication, privacy, trust boundaries, tutor state, deterministic verification, mastery, new dependencies, coherent workstream boundaries, and final Phase exit.
- Commits remain task-scoped or coherent-workstream-scoped with validation gates; no giant Phase commit and no unrelated changes.
- Codex never independently declares a Phase complete. Phase 3 still requires a real pilot and measurable post-test improvement; code, unit tests, and infrastructure alone are insufficient.
- Recovery continues to use Git/GitHub, the current PR, `TASK_INDEX.md`, the ACTIVE task, `09_DEV_WORKFLOW.md`, and relevant architecture/product docs as authoritative sources. Current-state snapshots are supplemental only.
- The operating principle is: ChatGPT designs the Phase/workstream, Codex executes inside boundaries, deterministic gates run, ChatGPT reviews meaningful checkpoints, Codex continues, and ChatGPT performs the Phase exit review.
