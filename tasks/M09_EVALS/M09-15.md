# M09-15 — Harden Primary-Skill Ordering Contract

Status: ACTIVE
Codex: YES

## Goal

Make TutorAI consistently place the single best primary controlled skill at `analysis.skills[0]`, while keeping genuinely relevant controlled secondary skills after it.

This task addresses the residual live-eval pattern found in M09-14 without changing taxonomy, eval fixtures, or scorer semantics.

## Required prompt semantics

The analysis contract must clearly say:

1. `skills[0]` is the **primary skill**.
2. Choose exactly one primary skill: the best controlled skill representing the main learner task / pedagogical objective.
3. Put supporting or prerequisite skills after the primary only when they are materially relevant.
4. Prefer an explicit higher-level target skill when the prompt asks for that target and its prerequisites are merely steps.

Examples of intended ordering semantics:

### Rational simplification

For a problem that asks to simplify a rational expression and state its domain:

```text
primary:
algebra.rational_expression.simplify

secondary if relevant:
algebra.rational_expression.domain
```

### Expression simplification

For a problem whose main task is to simplify an algebraic expression using distribution and combining like terms:

```text
primary:
algebra.expression.simplify

secondary if relevant:
algebra.expression.distributive_property
algebra.expression.combine_like_terms
```

### Basic identity

For a problem explicitly asking to expand using a basic identity:

```text
primary:
algebra.identity.basic
```

Distributive property may be a prerequisite/supporting skill, but must not replace the explicit identity objective as primary.

These examples express taxonomy semantics; do not special-case literal eval prompts.
