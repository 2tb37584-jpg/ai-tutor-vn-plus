## Required 20 new cases

### Signed-number operations (+2)

1. `g8-signed-numbers-subtract-negative-001`
   - Problem: `Tính -8 - (-3).`
   - Skill: `arithmetic.signed_number_operations`
   - Expected answer: `-5`
   - Misconception: treating subtraction of a negative as subtraction of a positive.
   - Use contextual forbidden forms such as `kết quả là -5`, `đáp án là -5`; do not forbid bare `-5`.

2. `g8-signed-numbers-order-operations-001`
   - Problem: `Tính -3 + 2(-4).`
   - Skill: `arithmetic.signed_number_operations`
   - Expected answer: `-11`
   - Misconception: sign handling and multiplication-before-addition.
   - Use contextual forbidden forms; do not forbid bare `-11`.

### Distributive property (+2)

3. `g8-distributive-leading-subtraction-001`
   - Problem: `Khai triển 5 - 2(x + 3).`
   - Skill: `algebra.expression.distributive_property`
   - Expected answer: `-2x - 1`
   - Misconception: failing to distribute the negative coefficient to every term.

4. `g8-distributive-fraction-001`
   - Problem: `Khai triển (1/2)(6x - 4).`
   - Skill: `algebra.expression.distributive_property`
   - Expected answer: `3x - 2`
   - Misconception: applying a fractional multiplier to only one term.

### Combine like terms (+2)

5. `g8-combine-like-terms-implicit-one-001`
   - Problem: `Thu gọn x - 4x + 2.`
   - Skill: `algebra.expression.combine_like_terms`
   - Expected answer: `-3x + 2`
   - Misconception: missing the implicit coefficient 1.

6. `g8-combine-like-terms-constants-001`
   - Problem: `Thu gọn 6x + 3 - 2x - 8.`
   - Skill: `algebra.expression.combine_like_terms`
   - Expected answer: `4x - 5`
   - Misconception: mixing variable and constant groups or losing the sign of `-8`.

### Expression simplify (+2)

7. `g8-expression-simplify-leading-minus-001`
   - Problem: `Rút gọn 2(x + 3) - (x - 4).`
   - Skill: `algebra.expression.simplify`
   - Expected answer: `x + 10`
   - Misconception: failing to change both signs inside a subtracted parenthesis.

8. `g8-expression-simplify-cancel-variable-001`
   - Problem: `Rút gọn 3(x + 2) - 3x + 5.`
   - Skill: `algebra.expression.simplify`
   - Expected answer: `11`
   - Misconception: not recognizing complete cancellation of variable terms.
   - Use contextual leakage forms such as `kết quả là 11`, `đáp án là 11`; avoid bare `11`.

### Equivalent equation transformation (+2)

9. `g8-equivalent-transform-negative-divide-001`
   - Problem: `Từ -3x = 12, hãy viết phương trình tương đương sau khi chia cả hai vế cho -3.`
   - Skill: `algebra.equation.equivalent_transform`
   - Expected answer: `x = -4`
   - Misconception: sign change when dividing by a negative number.
   - Do not add a verifier fixture.

10. `g8-equivalent-transform-multiply-001`
    - Problem: `Từ 2x/5 = 6, hãy viết phương trình tương đương sau khi nhân cả hai vế với 5.`
    - Skill: `algebra.equation.equivalent_transform`
    - Expected answer: `2x = 30`
    - Misconception: applying an operation to only one side.
    - Do not add a verifier fixture.

### Linear equation (+1)

11. `g8-linear-parentheses-verifier-001`
    - Problem: `Giải phương trình 3(x - 2) + 4 = 10.`
    - Skill: `algebra.linear_equation`
    - Expected answer: `4`
    - Use contextual leakage forms such as `x = 4`, `x=4`, `đáp án là 4`.
    - Add one verifier fixture using the existing verifier kind only:

```json
{"kind":"linear_equation","equation":"3*(x-2)+4=10","candidate":"4","expected_valid":true}
```

This increases linear-equation verifier fixtures from 3 to 4.

### Basic identities (+2)

12. `g8-identity-scaled-difference-square-001`
    - Problem: `Khai triển (3x - 2)^2 bằng hằng đẳng thức.`
    - Skill: `algebra.identity.basic`
    - Expected answer: `9x^2 - 12x + 4`
    - Misconception: missing the factor 2 in the middle term.

13. `g8-identity-scaled-difference-squares-001`
    - Problem: `Khai triển (2x - 5)(2x + 5) bằng hằng đẳng thức.`
    - Skill: `algebra.identity.basic`
    - Expected answer: `4x^2 - 25`
    - Misconception: incorrectly retaining a middle term.

### Factorization (+2)

14. `g8-factor-common-factor-001`
    - Problem: `Phân tích 6x^2 + 9x thành nhân tử.`
    - Skill: `algebra.factorization`
    - Expected answer: `3x(2x+3)`
    - Misconception: extracting only the numeric common factor or only `x`.
    - Do not add a verifier fixture.

15. `g8-factor-perfect-square-001`
    - Problem: `Phân tích x^2 - 6x + 9 thành nhân tử.`
    - Skill: `algebra.factorization`
    - Expected answer: `(x-3)^2`
    - Misconception: failing to recognize a perfect-square trinomial.
    - Do not add a verifier fixture.

### Rational-expression domain (+2)

16. `g8-rational-domain-scaled-linear-001`
    - Problem: `Tìm điều kiện xác định của (x + 1)/(3x - 12).`
    - Skill: `algebra.rational_expression.domain`
    - Expected answer: `x != 4`
    - Include both ASCII and Unicode inequality variants in leakage protection.

17. `g8-rational-domain-two-exclusions-001`
    - Problem: `Tìm điều kiện xác định của (x + 1)/((x - 2)(x + 5)).`
    - Skill: `algebra.rational_expression.domain`
    - Expected answer: `x != 2, x != -5`
    - Misconception: finding only one excluded denominator root.
    - Protect both exclusions in `first_turn_must_not_contain`, including `!=` and `≠` notation where useful.

### Rational-expression simplify (+3)

All three problems must require the student to state the domain restriction rather than revealing it in the problem.

18. `g8-rational-simplify-common-factor-001`
    - Problem: `Rút gọn (2x^2 + 6x)/(2x) và nêu điều kiện xác định.`
    - Skill: `algebra.rational_expression.simplify`
    - Expected answer: `x + 3, x != 0`
    - Misconception: canceling `x` without retaining the original-domain restriction.

19. `g8-rational-simplify-difference-squares-denominator-plus-001`
    - Problem: `Rút gọn (x^2 - 16)/(x + 4) và nêu điều kiện xác định.`
    - Skill: `algebra.rational_expression.simplify`
    - Expected answer: `x - 4, x != -4`
    - Misconception: losing the excluded value after cancellation.

20. `g8-rational-simplify-trinomial-001`
    - Problem: `Rút gọn (x^2 - 3x + 2)/(x - 1) và nêu điều kiện xác định.`
    - Skill: `algebra.rational_expression.simplify`
    - Expected answer: `x - 2, x != 1`
    - Misconception: factorization plus preservation of the original-domain restriction.

Do not add verifier fixtures to rational-expression cases.

## Leakage-fixture quality

For equation answers, include variants such as `x = -4` and `x=-4`.

For numeric-only answers, avoid bare numbers when they would create obvious false positives; prefer contextual forms such as `kết quả là 11` and `đáp án là 11`.

For rational-domain cases, protect both ASCII and Unicode inequality forms where useful.

For two-exclusion and rational-simplify cases, leakage protection must cover every required excluded value, not just one of them.
